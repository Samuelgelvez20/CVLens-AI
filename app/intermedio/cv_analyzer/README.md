# Analizador de currículums con IA

Aplicación de Streamlit que compara un currículum en PDF con la descripción de un puesto utilizando OpenAI y LangChain.

## Ejecución local

Desde la raíz del repositorio:

```bash
cd app/intermedio/cv_analyzer
python -m streamlit run app.py --server.port=8501
```
